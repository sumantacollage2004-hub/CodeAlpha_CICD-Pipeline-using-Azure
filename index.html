azure-pipelines.yml 
trigger:
  branches:
    include:
      - main
      - release/*

pool:
  vmImage: 'ubuntu-latest'

variables:
  acrName: 'myazureregistry.azurecr.io'
  imageName: 'my-webapp'
  tag: '$(Build.BuildId)'

stages:
  - stage: Build
    displayName: 'Build & Test'
    jobs:
      - job: BuildJob
        steps:
          - task: NodeTool@0
            inputs:
              versionSpec: '18.x'
          - script: npm install && npm test
            displayName: 'Install & Test'

  - stage: Containerize
    dependsOn: Build
    jobs:
      - job: DockerJob
        steps:
          - task: Docker@2
            inputs:
              command: 'buildAndPush'
              containerRegistry: '$(acrServiceConnection)'
              repository: '$(imageName)'
              tags: '$(tag)'

  - stage: Deploy
    dependsOn: Containerize
    jobs:
      - deployment: DeployToAppService
        environment: 'production'
        strategy:
          runOnce:
            deploy:
              steps:
                - task: AzureWebAppContainer@1
                  inputs:
                    azureSubscription: '$(azureServiceConnection)'
                    appName: 'my-webapp'
                    containers: '$(acrName)/$(imageName):$(tag)'

DEVOPS CONCEPTS

Core Azure DevOps Concepts

Master the fundamentals that power every automated pipeline

01
🔄

Continuous Integration

Automatically build and test code on every commit, catching bugs early before they reach production.

  • Trigger on branch push or PR creation
  • Run unit, integration & E2E tests
  • Static code analysis (SonarQube)
  • Publish test result artifacts
+ Learn More
02
🚀

Continuous Delivery

Every passing build produces a deployable artifact that can be released to any environment with one click.

  • Environment gates and approvals
  • Versioned release pipelines
  • Rollback on failure
  • Blue-green deployments
+ Learn More
03
📦

Infrastructure as Code

Provision and manage Azure resources declaratively using ARM templates, Bicep, or Terraform.

  • Bicep for native Azure IaC
  • Terraform for multi-cloud
  • ARM templates & JSON schemas
  • GitOps workflows
+ Learn More
04
🐳

Containerization

Package apps and dependencies into Docker containers for consistent, portable deployments across environments.

  • Dockerfile best practices
  • Multi-stage builds
  • Image scanning with Defender
  • AKS for orchestration
+ Learn More
05
🛡️

Shift-Left Security

Integrate security scanning directly into the pipeline — catching vulnerabilities before deployment.

  • SAST & DAST scanning
  • Dependency vulnerability checks
  • Secrets detection
  • Azure Policy as code
+ Learn More
06
📊

Observability

Instrument apps with distributed tracing, metrics, and logs for end-to-end system visibility.

  • Application Insights SDK
  • Azure Monitor dashboards
  • Log Analytics Workspace
  • Smart alert rules
